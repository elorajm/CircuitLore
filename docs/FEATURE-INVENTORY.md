# CircuitLore Feature Inventory

This document divides CircuitLore into major features. Each feature will receive its own implementation plan before development begins.

## F1 — Authentication and User Profiles

Students and adults need secure accounts.

Includes:

- Sign up
- Log in
- Log out
- Student profiles
- Parent/teacher profiles
- User roles
- Profile editing
- Account deletion
- Authentication protection

## F2 — Learning Journey

Controls how students move through CircuitLore.

Includes:

- Starting the learning journey
- Lesson order
- Lesson unlocking
- Continue where you left off
- Historical-to-modern timeline
- Navigation between learning sections

## F3 — Historical Storytelling

Introduces electricity through historical discoveries.

Includes:

- Historical figures
- Story scenes
- Dialogue/text
- Historical experiments
- Animated presentation
- Connection between discoveries and modern concepts
- Historical source information

## F4 — Electricity Lessons

Teaches the main electrical concepts.

Possible lesson topics:

- Electrical safety
- Electrical charge
- Current
- Voltage
- Resistance
- Conductors and insulators
- Open and closed circuits
- Series circuits
- Parallel circuits
- Modern electricity

## F5 — Interactive Activities and Quizzes

Allows students to practice what they learn.

Includes:

- Multiple-choice questions
- Interactive questions
- Lesson challenges
- Immediate feedback
- Quiz results
- Retry options
- Saved results

## F6 — Student Progress

Tracks the student's learning.

Includes:

- Completed lessons
- Current lesson
- Quiz results
- Completed challenges
- Circuit activities
- Progress percentage
- Continue learning
- Reset appropriate progress

## F7 — Virtual Circuit Lab

Allows students to build electrical circuits.

Initial components:

- Battery
- Wire
- Light bulb
- Switch
- Resistor

Includes:

- Component toolbox
- Circuit workspace
- Add components
- Move components
- Connect components
- Remove components
- Clear circuit
- Reset circuit

## F8 — Circuit Logic and Feedback

Determines whether the circuit works.

Includes:

- Component connections
- Open circuits
- Closed circuits
- Switch state
- Basic circuit validation
- Light bulb response
- Incorrect circuit feedback
- Challenge validation
- Series circuits
- Parallel circuits if scope allows

## F9 — Parent/Teacher Dashboard

Allows an adult to view student progress.

Includes:

- Student overview
- Completed lessons
- Quiz results
- Completed challenges
- Progress percentage
- Areas needing more practice

## F10 — AI Learning Assistant

Provides learning support without simply giving away answers.

Includes:

- Student hints
- Simple explanations
- Age-appropriate responses
- Circuit hints
- Lesson help
- AI error handling
- Usage limits
- Safety controls

## F11 — Animation and Visual Experience

Creates the historical-to-modern experience.

Includes:

- Historical character animations
- Scene transitions
- Historical environments
- Modern environments
- Circuit animations
- Interactive feedback
- Realistic-cartoon visual direction
- Reduced-motion accessibility option

## F12 — Learning Content Management

Stores and manages the educational content used by CircuitLore.

Includes:

- Lessons
- Historical content
- Questions
- Challenges
- Circuit challenges
- Content creation
- Content editing
- Content deletion
- Content ordering

## Feature Priority

### Must Have

- F1 Authentication and User Profiles
- F2 Learning Journey
- F3 Historical Storytelling
- F4 Electricity Lessons
- F5 Interactive Activities and Quizzes
- F6 Student Progress
- F7 Virtual Circuit Lab
- F8 Circuit Logic and Feedback

### Should Have

- F9 Parent/Teacher Dashboard
- F11 Animation and Visual Experience
- F12 Learning Content Management

### Could Have / Scope Dependent

- F10 AI Learning Assistant
- Advanced circuit simulation
- Additional historical figures
- Additional lesson paths
- Advanced animations
