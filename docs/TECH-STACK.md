# CircuitLore Technology Stack

## Frontend

### React

CircuitLore will use React for the user interface.

React is a good fit because CircuitLore contains many interactive parts, including:

- Learning scenes
- Historical characters
- Quizzes
- Student progress
- Dashboards
- Circuit components
- Circuit states

React will allow these pieces to be separated into reusable components.

### Vite

Vite will be used to create and run the React application during development.

---

## Language

### JavaScript

CircuitLore will use JavaScript.

I already have experience with JavaScript, which allows me to focus my new learning on React, Supabase, circuit modeling, animation, and other project-specific technologies.

---

## Styling

### CSS

CircuitLore will use CSS for the main visual design.

This gives me control over the custom realistic-cartoon educational style without depending heavily on a UI framework.

---

## Routing

### React Router

React Router will manage navigation between areas such as:

- Home
- Login
- Registration
- Student Dashboard
- Learning Journey
- Lessons
- Circuit Lab
- Adult Dashboard
- Admin Content Management

## Database and Backend Services

### Supabase

Supabase will provide the main backend services for CircuitLore.

It will be used for:

- PostgreSQL database
- Authentication
- User accounts
- Profiles
- Student progress
- Quiz results
- Learning content
- Adult/student relationships
- Circuit challenge progress

Supabase was also suggested by my CSE 499 instructor as an option worth exploring.

---

## Authentication

### Supabase Auth

Supabase Authentication will handle:

- Registration
- Login
- Logout
- Sessions

CircuitLore will add application-specific profiles and roles.

---

## Animation

CircuitLore will begin with CSS animation and may use Framer Motion for more advanced React animations.

Animation will be used for:

- Historical character entrances
- Scene transitions
- Educational demonstrations
- Lesson feedback
- Historical-to-modern transitions

The final animation approach may change after prototyping.

---

## Circuit Simulation

The Virtual Circuit Lab will use custom JavaScript logic.

The project will explore representing electrical circuits as connected data structures.

Possible concepts include:

- Nodes
- Connections
- Graph traversal
- Path finding

This will allow CircuitLore to determine whether a basic electrical path is complete.

## AI
