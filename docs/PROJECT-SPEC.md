# CircuitLore Project Specification

## Project Overview

CircuitLore is an interactive educational web application that teaches kids about electricity through history, storytelling, interactive lessons, challenges, and hands-on circuit building.

The experience begins with important people and discoveries from the history of electricity. Historical figures will help introduce concepts through a realistic-cartoon visual style. Each historical section will explain what was discovered, what it taught us, and how it connects to electricity today.

As students progress, the experience will transition from historical discoveries into modern electrical concepts and technology.

## Target Users

### Students
The primary users are students around ages 10–14 who are beginning to learn about electricity and electrical circuits.

Students should be able to:

- Create and manage an account.
- Move through the electricity learning journey.
- Complete interactive lessons.
- Take quizzes and complete challenges.
- Build and test circuits.
- Receive feedback and hints.
- Save and view their progress.

### Parents and Teachers
Parents or teachers should be able to view appropriate student learning progress, including completed lessons, challenges, and quiz results.

## Core Experience

CircuitLore should feel like an interactive journey rather than an online textbook.

The basic student experience will be:

1. Create an account or log in.
2. Begin the electricity learning journey.
3. Meet historical figures and learn about important discoveries.
4. See how each discovery connects to an electrical concept.
5. Complete interactive lessons and activities.
6. Answer quizzes and challenges.
7. Experiment in the virtual circuit lab.
8. Receive feedback and hints.
9. Save progress.
10. Continue into more advanced lessons and modern electrical applications.

## Visual Direction

CircuitLore will use a realistic-cartoon visual style.

Historical people, laboratories, electrical equipment, and environments should be recognizable while still feeling colorful, friendly, and engaging for younger students.

The visual environment should gradually move from historical settings into modern electrical technology as the student progresses.

Animations should support learning rather than simply being decoration.

## Core Technical Goals

CircuitLore will include:

- User authentication
- User profiles
- Full CRUD functionality
- Database-backed student progress
- Role-based access
- Interactive lessons
- Historical storytelling
- Quizzes and challenges
- Interactive circuit building
- Circuit validation and feedback
- Parent/teacher progress viewing
- Animation
- AI-assisted learning
- Responsive design
- Accessibility considerations

## Project Completion

The core project will be considered complete when a student can:

1. Create an account and log in.
2. Begin a learning path.
3. Complete historical and modern electricity lessons.
4. Complete an interactive activity.
5. Build and test a basic electrical circuit.
6. Complete a quiz or challenge.
7. Receive feedback.
8. Have progress saved in the database.
9. Return later and continue from saved progress.

A parent or teacher should also be able to view appropriate student progress.

Advanced animations, additional historical figures, additional lessons, advanced circuit simulations, and expanded AI features may be added as time allows.
